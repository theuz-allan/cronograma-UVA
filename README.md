## 💡 Sobre o projeto

O **Cronograma UVA** é uma plataforma web desenvolvida com o objetivo de facilitar a organização e o acompanhamento dos estudos para o vestibular da Universidade Estadual Vale do Acaraú.

A ideia surgiu da necessidade de ter um ambiente prático e intuitivo para organizar os conteúdos, acompanhar o progresso e manter uma rotina de estudos mais eficiente.

O projeto busca transformar o planejamento de estudos em uma experiência mais visual, organizada e acessível.

## 🚀 Funcionalidades

- 📅 **Cronograma de estudos:** organização dos conteúdos por disciplinas e datas.
- 📖 **Conteúdos programáticos:** acompanhamento dos assuntos que precisam ser estudados.
- ✅ **Controle de progresso:** acompanhamento das atividades concluídas.
- 📊 **Registro de questões:** controle da quantidade de exercícios resolvidos.
- 🎯 **Nível de aprendizagem:** classificação do desempenho em cada conteúdo.
- 📝 **Anotações:** espaço para registrar observações e dificuldades.
- 🔄 **Revisões:** organização de períodos destinados à revisão dos conteúdos.
